# Dungeon Architect

Dungeon Architect 是一款用 Python 和 pygame-ce 製作的單人地城拼圖遊戲。你會在 7×7 地圖上挑選並旋轉房間卡，把門接到既有的通路上。一張卡可能讓你開出新分支，也可能封住下一步能走的路。

## 啟動遊戲

在專案根目錄執行。專案以 Python 3.14.7 開發。

```sh
python -m pip install -r requirements.txt
python main.py --seed 42
```

省略 `--seed` 時預設為 `42`。換一個整數可以試不同的牌序。

想先重現一局已驗證的勝利，可用 `--seed 159`。也可執行 `python -m engine.demo`，依 `data/mvp_demo.json` 在不開視窗的情況下重播同一局。三卡保底只保證當下有合法選項，不保證每個 seed 都能通關。

## 怎麼玩

每次先從三張卡中挑一張，再決定方向和位置。新房間必須接上一間可達的房間，與每個已建鄰房都要門對門、牆對牆，門也不能朝向地圖外。

開局會顯示起點、兩座祭壇與封印核心。親自進入兩座祭壇後，核心才會解鎖；沿相通的門進入核心即勝利。HP 歸零即敗北。勝負畫面都能用 `N` 或 Restart 重開。

| 操作 | 用途 |
|---|---|
| 點卡片或按 `1`／`2`／`3` | 選卡，各卡分別保留自己的預覽方向 |
| `R` 或 **Rotate**／`Q` | 順時針／逆時針旋轉 90° |
| 移動滑鼠至地圖 | 查看放置預覽，青綠色表示可放置 |
| 左鍵點合法格 | 建造一間房，角色移入，換下一手牌 |
| 方向鍵／`WASD` 或點相鄰已建房間 | 沿相通且未上鎖的門走一格，免費回溯並保留手牌 |
| `F` 或 **Seal** | 循環選擇新卡要封閉的門，再點合法格建造；再次循環可取消 |
| `C` 或 **Chisel** | 啟用後點目前房間旁的既有房間，將雙方共用的牆鑿成相通門；再次按 C 取消 |
| `H`、`?` 或 **Help** | 開啟／關閉遊戲內操作指南 |
| `N` 或 **Restart** | 用相同 seed 重開 |
| `Esc` 或關閉視窗 | 先關閉操作指南；指南未開啟時離開遊戲 |

只要地圖還有可用的普通房型，手牌就至少有一張能在某個方向放下。若無處可建，畫面會顯示 **No normal placement**，你仍可走訪已建房間、嘗試工具或重開，不會直接判定敗北。

建造後會自動進房，首次進入普通房間時結算一次事件：補給增加 Supplies、危險扣 HP、普通事件不改變資源。卡片只預告類別，實際結果在進房後顯示。回頭走不會重複領取獎勵或受傷。畫面上方顯示 HP／Supplies，右下保留最後一個事件及實際資源變化。

目前的 HP 6／6、Supplies 2／5、補給 +1 與危險 −1 都是[原型設定](data/prototype_config.json)中的暫定試玩值。封門花 1 Supplies、每局最多 3 次；鑿壁花 2 Supplies、每局最多 2 次；第一座親自啟動的祭壇補給 1 Supplies。工具僅在成功時扣費，不能繞過核心鎖定，沒有自動資源再生。

## 目前版本

MVP 已串接開局、建造、免費移動、首次進房事件、HP／Supplies、工具、祭壇、核心、勝負與重開。關卡、目標數量、門向、工具費用與上限皆可設定。自動化已驗證完整通關流程；實際桌面操作與縮放仍待人工驗收，規則與平衡數值仍為原型提案。沒有 Boss 戰鬥。
