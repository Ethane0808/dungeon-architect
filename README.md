# Dungeon Architect

Dungeon Architect 是一款用 Python 和 pygame-ce 製作的單人地城拼圖遊戲。你會在 7×7 地圖上挑選並旋轉房間卡，把門接到既有的通路上。一張卡可能讓你開出新分支，也可能封住下一步能走的路。

## 啟動遊戲

在專案根目錄執行。專案以 Python 3.14.7 開發。

```sh
python -m pip install -r requirements.txt
python main.py
.\.venv\Scripts\python.exe main.py --seed 42
```

一般啟動會隨機選一個種子。可用 `python main.py --seed 42` 指定地圖、牌序與事件。按 N 會重玩同一個種子。加上 `--fullscreen` 可直接以全螢幕啟動。

啟動後會先進入探索大廳。按 `Enter` 開始探索，或按 `H` 查看操作指南。遊戲中按 `L` 回到大廳，再按 `Enter` 即可接續本局；勝負結算後則會用同一個 seed 開新局。

想先重現一局已驗證的勝利，可用 `--seed 159`。也可執行 `python -m engine.demo`，依 `data/mvp_demo.json` 在不開視窗的情況下重播同一局。三卡保底只保證當下有合法選項，不保證每個 seed 都能通關。

## 怎麼玩

教學中的 B4 固定示範飛箭陷阱（扣 1 生命），C4 固定示範補給（加 1 補給）。回走不會重複觸發事件；接通第一座祭壇的通道就會喚醒守衛，親自走進祭壇才會啟動祭壇。角色旁的說明框會交代每一步的結果與下一個操作，教學同樣使用正式守衛移動規則。

第一次遊玩可在大廳點「新手教學」或按 T。六階段短教學讓你實際選牌、旋轉施工、免費回走、規劃遠端位置、按 G 逐格前往入口並以 Enter 確認建造，最後走進兩座祭壇與核心。畫面只標出當前目標；可隨時跳過、按 N 重練，完成後選「開始冒險」或「重玩教學」。原本的探險進度會保留。一般遊戲首次遇到守衛、迴路、受傷、帶刺寶箱或封門機會時，會短暫顯示不影響操作的提示。三頁探險手冊仍可按 H 查閱。

每次先從三張卡中挑一張，再決定方向和位置。新房間必須接上一間可達的房間，與每個已建鄰房都要門對門、牆對牆，門也不能朝向地圖外。MVP 的實際施工只能從角色目前房間的相鄰相通門進行，不能在遠處直接放置或傳送。

開局會顯示起點、兩座祭壇與封印核心。親自進入兩座祭壇後，核心才會解鎖；沿相通的門進入核心即勝利。HP 歸零即敗北。勝負畫面都能用 `N` 或 Restart 重開。

| 操作 | 用途 |
|---|---|
| 點卡片或按 `1`／`2`／`3` | 選卡，各卡分別保留自己的預覽方向 |
| `R` 或 **Rotate**／`Q` | 順時針／逆時針旋轉 90° |
| 移動滑鼠至地圖 | 綠色實框是目前可施工格；青色虛框是全圖合法、可先規劃的格 |
| 左鍵點綠格 | 立即建造一間房，角色移入，換下一手牌 |
| 左鍵點青色虛框 | 只建立施工計畫，顯示藍圖、最短路線、入口與距離，不消耗狀態 |
| `G` 或計畫面板的 **Go** | 逐格自動走向入口；再按一次暫停，每一步都會照常推進守衛與事件 |
| `Enter` | 抵達計畫入口後明確確認施工；導航本身永遠不會自動建造 |
| 方向鍵／`WASD` 或點相鄰已建房間 | 沿相通且未上鎖的門走一格，免費回溯並保留手牌 |
| `F` 或 **Seal** | 循環選擇新卡要封閉的門，再點合法格建造；再次循環可取消 |
| `C` 或 **Chisel** | 啟用後點目前房間旁的既有房間，將雙方共用的牆鑿成相通門；再次按 C 取消 |
| `H`、`?` 或 **Help** | 開啟／關閉遊戲內操作指南 |
| `F2` 或右上方的 **繁中／EN** | 即時切換繁體中文與英文，保留目前進度。正常離開後會記住語言偏好 |
| `M` 或 **回復包** | 花 2 補給恢復 1 生命。滿血或補給不足時不扣費 |
| `F11` | 切換全螢幕；畫面會維持比例並自動置中 |
| `N` 或 **Restart** | 用相同 seed 重開 |
| `Esc` 或關閉視窗 | 先關閉操作指南或取消施工計畫；兩者都沒有時才離開遊戲 |

每次發牌時，只要整個可達地城的出口還有普通房型可放，就保證至少一張牌能用；保底不保證該牌能在角色腳邊施工。遠處合法格可先規劃，再用 G 沿既有門路逐格前往入口。自動行走不耗補給、不換牌、不用 RNG，也不會跳過 `move()`；遇到首次事件、祭壇、HP 變化、終局或守衛預告格會立即停下。守衛佔住唯一施工通道時，必須先走動引開守衛，或從其他通道抵達施工入口。地圖上沒有普通放置位置時，仍可走訪已建房間或嘗試鑿壁。若施工會封閉最後出口，而且區內沒有可推進的目標或鑿壁出路，落子前會出現警告；確定封閉後可按 N 重開。

建造後會自動進房。卡面顯示房型的事件傾向，首次進房才揭露遭遇。補給房可找到 1 或 2 份口糧，危險房可能遇到飛鏢、落石、荊棘或帶刺寶箱。安靜房沒有資源變動，遺物可同時恢復 HP 與補給。右下方會顯示事件及實際變化。同一個 seed 與操作順序可以重現結果，回頭走也不會重複觸發陷阱。

遇到帶刺寶箱時，可按 **E** 或點擊 **Open chest**，花 1 HP 換最多 2 補給，也可以先離開再回來。背包已滿或只剩 1 HP 時會保留寶箱。想直接試玩，可用 `python main.py --seed 0` 開局，選第一張牌，直接放在起點上方的 A3。

進入或回訪未開啟的帶刺寶箱房時，房間會以金框標示，右下資訊區會出現開箱按鈕，並顯示生命費用及實際可取得的補給。提示不遮擋地圖，可繼續點擊建造或移動，也可按 E 開箱。離開房間後提示收起。飛鏢拖尾、落石墜落、荊棘收攏、補給光點及回血光環會在事件發生時短暫播放，動畫期間仍可操作。

**迴路獎勵**　兩個出口原本就能繞路相通時，蓋房接起它們，或在兩間房之間鑿出捷徑，每新增一條獨立迴路就得到 1 補給。補給以背包容量為限，走過舊路不會重領。使用 seed 42，將第 1 張按 R 放在 A3，走回 A4，再將第 2 張按 Q 放在 B4，最後把第 1 張按兩次 R 放在 B3，即可圍出第一圈。

在大廳或遊戲中按 **H** 開啟三頁探險手冊。用左右方向鍵或畫面按鈕翻頁，按 **H** 或 **Esc** 返回遊戲。

預設地圖有兩格藤蔓尖石與一口古井，開局即可看見位置。藤蔓尖石不能建造、通行或鑿開。接通古井後，首次走入可恢復 1 生命，滿血進入也會用掉井水。乾井仍可通行。

目前的初始血量為 5／5，補給為 2／5。封門花 1 補給，每局最多 3 次。鑿壁花 2 補給，每局最多 2 次。第一座親自啟動的祭壇給予 1 補給。工具僅在成功時扣費，不能繞過核心鎖定，沒有自動資源再生。各項試玩數值收在[原型設定](data/prototype_config.json)。

## 目前版本

畫面左側的守衛警戒條會隨成功建造累積。首次接通任一祭壇，或成功建成第 11 間普通房時，巡路守衛就會甦醒；接通祭壇只會喚醒守衛，仍須親自進入才能啟動祭壇。守衛甦醒時會先標出下一步，之後每走一步或成功建造一間房，守衛就沿醒目的金色箭頭前進一格。施工路線不能穿過守衛。碰到守衛損失 1 HP，守衛隨即退回起點。

飛鏢、落石與荊棘都是首次進房時結算的一次性陷阱；觸發當下會播放加強的醒目特效，結束後不在房間永久留下陷阱圖示，重訪也不會再次受傷。平靜事件只顯示文字紀錄，不播放地圖特效。未開啟的帶刺寶箱會持續顯示，成功領取後改成清楚的開啟空箱，且不能重複領取。

一般補給寶箱在首次進房時自動結算獎勵，播放約半秒的開箱動畫，並浮出實際增加的補給。之後留下打開、較暗的空箱，重訪時維持空箱狀態。背包已滿時顯示「補給已滿」，寶箱仍會變成空箱。動畫期間可以繼續操作。
